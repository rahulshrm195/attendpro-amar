What's new
v1.2.7November 2026 — paid leave
  • 🌴 Paid leave (PL) — for days with no work that you still pay, like a festival holiday. Paid as a full day, but never counted as present or absent
  • ⌨️ Daily Mark: a PL button, key L; ⇧L marks everyone (or the "Paid leave" button in Mark everyone)
  • 📅 Shown in its own colour in the Register (PL, with a PL count in Total), calendars, Hisab month view, Today and the PDFs
v1.2.6November 2026 — opening balances, today's advances
  • 💰 Today's attendance shows today's advances — a new Advance column with the note, and the day's total at the bottom
  • 📒 Add an opening balance to anyone — from their details (or press O), not only when adding them
  • 📅 Opening balances are dated on the join date (existing ones moved too), so every Ledger range counts them correctly
  • ➖ The Hisab card shows the opening balance with its sign and kind — e.g. "Opening balance (advance) −₹2,000"
  • 🏷️ Changing an opening balance between advance and pending salary now updates its label too
v1.2.5November 2026 — dialogs and the keyboard
  • ⌨️ The cursor moves into a dialog when it opens — Enter / Space press the highlighted button, Tab stays inside, Esc closes and returns the cursor
  • 👤 A person's details open on + Advance — or press A advance, D deduct, L ledger, E edit
  • 🔎 Add advance: type to find the person — the list opens straight away and narrows as you type (no drop-down); deactivated staff are no longer listed
v1.2.4November 2026 — day total, day keys everywhere
  • 🧮 Total advances for the day at the bottom of Daily Mark — saved + typed, updates as you type
  • 📅 [ ] change the day from the Advance, Note and Remark boxes too
  • 🛟 Nothing typed is lost — changing the day (keys, ‹ › or the date box) with an unsaved advance or remark asks first, then saves it
v1.2.3November 2026 — Help & guide, one-key marking
  • ⚡ One key per person in Daily Mark — 1/P Full, H Half, O OT, D/2 Double, 0/A Absent marks and jumps to the next person; Backspace clears
  • 👥 ⇧ + the same key marks everyone not marked yet (⇧1 = all Full); ⇧ Backspace clears the day
  • ↔️ Values are one Tab stop — ← → pick a value, Tab goes straight to ✕ → Advance → Note → Remark; ↑ ↓ move between people
  • 🌙 Night mode: the Advance / Remark box no longer hides what you type
  • 📖 Help & guide — a full guide to every page, feature and shortcut, inside the app (menu → Help & guide, Settings, or ⌘K → ? → Enter)
  • 🔎 Search the guide — or type a word in ⌘K ("undo", "settlement"…) to jump to the right topic
  • 🖨️ Print / Save as PDF — the whole guide as a document, e.g. to share with new staff
  • 👥 For each role — employees see the parts that apply to them
v1.2.2November 2026 — Fast keyboard marking
  • ⌨️ Daily Mark with Tab / Space / Enter — opens on the first person not marked yet; Tab goes 0 → ½ → 1 → 1.5 → 2 → Advance → Note → Remark → next person, and after the last person to Save all
  • ⚡ Mark everyone not marked yet — Full, Half, OT, Absent or Double in one go, then fix the few exceptions. Clear all for the day too
  • ↩️ Undo — every mark, clear and "mark everyone" can be undone from the message or with ⌘Z / Ctrl Z
  • 📅 [ ] and T — previous / next day and today · / find a person · ? all shortcuts
  • 🔎 ⌘K + a letter — D Daily Mark, R Register, H Hisab, A Add advance… On a person: Enter = details, ⇧Enter = add advance
  • 💰 Faster advances — type the name, Tab, amount, Tab, note, Enter saves
